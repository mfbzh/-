# Портфолио Ильи

Статический сайт для GitHub Pages. Основная версия: `index.html`, `styles.css`, `app.js`. Демоверсии: `demo-apex.html` и `demo-library.html`.

## Проверка

```sh
node --check app.js
node --check apex.js
```

Шрифты Manrope и Oswald размещены локально в `assets/fonts`; лицензии OFL находятся рядом. Страница не требует Google Fonts или сторонних скриптов.

## Безопасность

CSP в HTML ограничивает скрипты, медиа и шрифты текущим источником. Вставка основного содержимого кейсов использует DOM API. Остальные HTML/SVG-шаблоны содержат только статические данные: не передавать в них пользовательский HTML.

GitHub Pages не применяет произвольные HTTP-заголовки из `_headers`. Защита от встраивания (`Content-Security-Policy: frame-ancestors 'none'`, `X-Frame-Options: DENY`) требует хостинга или прокси, позволяющего задать HTTP-заголовки. В HTML-meta эта директива не работает. Текущая публикация и адрес сохранены; миграция хостинга не выполнялась.
