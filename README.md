# Портфолио Ильи

Статический сайт. Все файлы для публикации находятся в корне репозитория.

Для GitHub Pages загрузите файлы сайта в корень репозитория, затем выберите Settings → Pages → Deploy from a branch → main / root.

Локальный просмотр: `python3 -m http.server 8000`.

Контакт сейчас ведёт в Telegram @IMuschinsky. Вымышленные проекты «APEX» и «Лист» обозначены как концепты. «Кремень» обозначен как демопроект. Видео и страницы книги взяты из предоставленных работ.

Изображение автомобиля создано для демонстрационного концепта APEX. Данные клиентов и реальные проекты ателье не заявлены.

Перед открытой публикацией проверьте разрешения на демонстрацию клиентских материалов. Здесь опубликованы только выбранные страницы книги, без исходных документов и переписок.

Главный экран портфолио сохраняет интерьерную фотографию: Unsplash, https://images.unsplash.com/photo-1600210492486-724fe5c67fb0 . APEX представлен отдельной карточкой в разделе работ.
